# Leetcode DSA Java

A comprehensive collection of Data Structures and Algorithms (DSA) solutions implemented in Java. This repository contains solutions to LeetCode problems with a focus on understanding core algorithms and data structures.

## About

This repository is dedicated to solving and mastering DSA concepts through LeetCode problems. Each solution is implemented in Java and includes explanations of the approach and time/space complexity analysis.

## Contents

The repository includes solutions covering:

- **Arrays & Strings**
  - Two Sum
  - Three Sum
  - Merge Sorted Array
  - Remove Duplicates Array
  - Remove Element
  - Best Time To Buy & Sell Stock
  - Maximum Product
  - Reverse Integer
  - String To Integer
  - Palindrome

- **Linked Lists**
  - Remove Nth Node

## Repository Structure

```
Leetcode-DSA-Java/
├── Two Sum/                       # HashMap-based solution for finding two numbers

├── Palindrome/                    # Palindrome number checking
├── Best Time To Buy & Sell Stock/ # Stock trading profit optimization
├── Merge Sorted Array/            # Merging two sorted arrays
├── Maximum Product/               # Maximum subarray product
├── Remove Duplicates Array/       # Removing duplicates from array
├── Remove Element/                # Removing specific element from array
├── Remove Nth Node/               # Removing Nth node from linked list
├── Reverse Integer/               # Reversing integer values
├── String To Integer/             # Converting strings to integers
├── README.md                      # This file
└── .vscode/                       # VS Code editor configuration
```

Each problem solution contains:
- **`{ProblemName}.java`** - Java implementation of the solution
- **`{problemname}.txt`** (optional) - Detailed explanation of approach and complexity

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/adityasri2501/Leetcode-DSA-Java.git
   cd Leetcode-DSA-Java
   ```

2. Navigate to the problem you want to solve:
   ```bash
   cd "Problem Name"
   ```

3. View and review the Java implementation:
   ```bash
   cat ProblemName.java
   ```

4. Compile and run the solution (if main method is present):
   ```bash
   javac ProblemName.java
   java Solution
   ```
