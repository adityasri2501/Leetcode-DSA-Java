# Leetcode DSA Java

A comprehensive collection of Data Structures and Algorithms (DSA) solutions implemented in Java. This repository contains solutions to LeetCode problems with a focus on understanding core algorithms and data structures.

## About

This repository is dedicated to solving and mastering DSA concepts through LeetCode problems. Each solution is implemented in Java and includes explanations of the approach and time/space complexity.

## Contents

The repository includes solutions covering:

- **Arrays & Strings**
- **Linked Lists**
- **Trees & Graphs**
- **Sorting & Searching**
- **Dynamic Programming**
- **Hash Tables & Sets**
- **Stacks & Queues**
- **Heaps**
- **Greedy Algorithms**
- **Backtracking**
- And more...

## Structure

Each problem solution is organized by topic, making it easy to find and review solutions for specific DSA concepts.

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/adityasri2501/Leetcode-DSA-Java.git
   cd Leetcode-DSA-Java
   ```

2. Navigate to the problem you want to solve
3. Review the Java implementation
4. Understand the algorithm and approach
